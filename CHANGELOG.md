# Changelog

## Unreleased

### Fixed

- SARIF `artifactLocation.uri` now percent-encodes each path segment, so a path such as `my files/note.ts` becomes `my%20files/note.ts` ([#323](https://github.com/quality-gates/messcript/issues/323)). Characters such as `%`, `#`, and `?` are encoded too. Other formats still print the plain path.
- `UnusedPrivateField` and `UnusedPrivateMethod` no longer count `ClassName.member` or `ClassName["member"]` as a use of an instance private member ([#320](https://github.com/quality-gates/messcript/issues/320)). That access reads the constructor, so it now marks only static private members used.
- `UnusedPrivateField` and `UnusedPrivateMethod` now treat a numeric key such as `this[0]` as that key only, like `this["other"]` ([#319](https://github.com/quality-gates/messcript/issues/319)). It no longer suppresses every private-member finding in the class.
- `UnusedPrivateField` and `UnusedPrivateMethod` now count `ClassName["member"]` as a use of a static private member, matching `ClassName.member` and `this["member"]` ([#318](https://github.com/quality-gates/messcript/issues/318)). A non-literal key, such as `ClassName[key]`, suppresses that class's private-member findings the same way `this[key]` does.
- `GlobalVariable` now treats only `Object.assign(...)` and `Object["assign"](...)` as writing their first argument ([#317](https://github.com/quality-gates/messcript/issues/317)). Passing module state to another object's `assign` method, such as `logger.assign(state)`, is no longer reported.
- `CamelCaseMethodName`, `ShortMethodName`, and `BooleanGetMethodName` now see object-literal methods and get/set accessors, and parameter-naming rules see their parameters ([#304](https://github.com/quality-gates/messcript/issues/304)). Each member is its own group, because an object literal cannot overload. A property whose value is a function expression or arrow function is unchanged.
- `LackOfCohesionOfMethods` no longer links methods through free identifiers or bare calls whose names match a class member ([#303](https://github.com/quality-gates/messcript/issues/303)). Only receiver-qualified access (`this.x`, `this["x"]`, and `ClassName.x` in static methods) counts as shared state or a receiver call, including when detecting trivial accessors. Classes that a stray `left` or `bumpLeft()` used to glue together may now report a higher LCOM4. A method that touches no instance state is still a pure helper and does not add a group.
- `ExitExpression` and `DevelopmentCodeFragment` no longer report calls whose root name is a local declaration, such as `process.exit(1)` on a `process` parameter or `console.log()` on a `console` parameter ([#294](https://github.com/quality-gates/messcript/issues/294)). Both rules and `ImplicitInput`/`ImplicitOutput` now share one host-global resolver, so they agree on what `process`, `console`, `window`, and `exit` refer to. Names from `unwanted-functions` and the `debug.*` defaults still match a locally bound root, such as `const logger = pino()`.
- Every naming rule now applies the same React component and hook exemption ([#293](https://github.com/quality-gates/messcript/issues/293)). `CamelCaseVariableName`, `CamelCasePropertyName`, and `CamelCaseParameterName` no longer report PascalCase components such as `const Header = () => <h1 />`. Component- and hook-valued class properties (`static readonly Fallback = () => <span />`) and parameters are recognised too, so `ConstantNamingConventions`, `ShortVariable`, and `LongVariable` skip them. `ShortVariable` and `LongVariable` also skip hooks (`useX` functions). Expect fewer findings if you relied on these rules reporting PascalCase arrow functions or long hook names.
